# v9.3 Dashboard - Kullanıcıya Özel Takip Listesi

- Dashboard üstüne kompakt "Takip Listem" alanı eklendi.
- Kullanıcı plaka seçip kaldırabilir; seçim anında kaydedilir.
- Kayıt anahtarı oturumdaki `fts_user.id` / kullanıcı adına göre ayrılır. Böylece aynı bilgisayarı kullanan farklı FTS kullanıcılarının listeleri birbirine karışmaz.
- Eski `fts_tracked_vehicles` kaydı ilk kullanımda mevcut kullanıcıya taşınır.
- Takip listesi varsa Dashboard varsayılan olarak haritada yalnızca bu araçları gösterir.
- "Sadece Takibim / Tüm Filo" ile görünüm anında değiştirilebilir.
- Plaka kartında canlı GPS durumu ve hız gösterilir; karta tıklanınca mevcut VehicleDrawer açılır.
- Mevcut Mobiliz yenileme, harita, alarm, drawer ve 30 saniyelik veri akışı değiştirilmedi.
